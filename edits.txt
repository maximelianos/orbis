### Trajectory encoding

This is the encode function to convert (x, y) coordinates into velocity and normalize:

X_MAX = 100 # meters
dx_norm = (x_t - x_{t-1}) / X_MAX

Decode to get (x, y) coordinates from normalized velocity:

x = cumsum * X_MAX

The scipt loaders_for_projects/nuplan_dataloader.py implements these functions.
It is based on MultiHDF5DatasetMultiFrameIdxMappingOdometry like nuplan_visualize.py.

### Trajectory prediction model

**Cross-attention block**

Implemented a CrossAttention block, that doesn't add the positional embeddings.
This class consists of fully connected layers, normalization and cross-attention.
SpatialBlock and TemporalBlock is based on CrossAttention class. The SpatialBlock contains additionaly only the positional embedding .

**Spatial block**

Created SpatialBlock with cross-attention in blocks.py. Inherits from CA block.
It follows the implementation in networks/DiT/dit.py, imports the 2d embedding function.

The SpatialBlock accepts latent representations of images in format (BxT, C, H, W) and outputs aggregated tokens (BxT, C) by using cross attention.
- it processes frames independently for performance reasons
- it has 2D positional embedding, no time embedding

**Temporal block**

Implemented TemporalBlock in blocks.py. Inherits from CA block. It imports the 1d embedding function from networks/DiT/dit.py.

This block accepts context tokens in format (B, N, C), adds 1D positional encoding, applies cross attention to predict (B, M, C).

**Trajectory diffusion**

The model is a diffusion transformer.

1. Implemented TrajectoryModel in file ./model.py that trains for predicting the next trajectory point using flow matching.

It follows models/second_stage/fm_model.py in implementation. The model takes batch['images'] and batch['velocity'] from NuPlanVelocityDataset.
- it first encodes the images with the frozen tokenizer
- then processes the latent images independently with SpatialBlock
- then it runs diffusion iterations on the extracted latents to predict the next trajectory token. The final trajectory token is convert to the normalized trajectory velocity using a fully connected layer

2. Implemented train_nuplan.py, following main.py. The configuration for training is in nuplan.yaml.

I encode and decode the trajectory using nuplan_dataloader.py.

Common features:
- checkpoint saving
- an option to only test the trained model

Implemented AdaLN in SpatialBlock and TemporalBlock. The condition is the timestep in diffusion process.
